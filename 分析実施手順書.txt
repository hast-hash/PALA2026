# The Fall of Robespierre 文体分析:再検証のための手順書

前回の一連の分析を通じて判明した落とし穴・改善点を反映した、再実行用の手順書。

---

## 0. 着手前に:今回新たに浮上した前提問題への対応

**Act II・III自体にColeridgeの加筆がある可能性**が、前回の検証終盤で指摘された。これは「Act II・IIIを純粋なSouthey基準として使う」という設計全体の土台に関わるため、再検証を始める前に以下のいずれかの立場を明確にしておくこと。

- (a) この可能性は保留し、従来通りAct II・IIIをSouthey基準として扱う(前回と同条件での再現性確認が目的の場合)
- (b) 書誌学的根拠(異本比較・書簡等)を先に調べ、Act II・IIIの中でColeridge加筆が疑われる箇所があれば、それを参照群・比較対象から除外してから進める

どちらの立場を取るかによって、以下の手順の一部(特にStep2でAct II・IIIを「既知のSouthey基準」として扱ってよいか)が変わる。

## 1. コーパス準備段階

### 1.1 語数カウントの基準統一

- ト書き(`[Exit.]`等)・話者名を含めるかどうかを、**テスト対象・参照テキストすべてで統一する**こと。前回はCoSou_Act1〜3(ト書き含む)と、他の参照テキスト(dialogue_onlyでト書き除去済み)とで基準が不統一だったまま進めた経緯がある。統一しない場合は、その旨をレポートに明記し、結果解釈時に割り引いて考えること
- 語数は必ず実測(`wc -w`等)で確認する。申告値と実測値に数%のズレが生じることは珍しくない(前回、Osorio・Wat Tyler等で実際に発生)

### 1.2 参照テキストの選定基準

- **時代の近さ**:検証対象(1794年)から離れるほど、著者本人のスタイルドリフト・時代的な言語変化がノイズになる。可能な限り1790年代の作品を優先する
- **ジャンルの近さ**:韻文劇(対話体)であることを優先する。叙事詩・独白詩(地の文中心)は三人称代名詞・接続詞の分布が構造的に異なり、著者差より大きなノイズ源になりうる
- **著者混入の確認**:候補テキストに共作者の手が入っていないか、事前に書誌情報を確認する(前回、Joan of Arcにおける Coleridge混入、Fall of Robespierre Act II/IIIの誤ラベルという2つの実例があった)
- **分量のバランス**:著者クラス間で総語数が大きく偏らないようにする。偏りが大きい場合(前回はBaillie 3作品で6万語 vs Southey 2作品で1万語)、GI法の`windowImposters`・`equalSampleSize`オプションで緩和できるが、根本的な偏りは残るため、結果解釈時に留意する

### 1.3 分析単位の切り出し

- Rolling Deltaで検出した分割点を境に断片化する際は、**語数ベースで機械的に境界を確認**すること(手作業でファイルを分けた場合、Pythonで元ファイルとの一致を検証する)
- 断片が短くなりすぎる場合(300語未満)、そこから得られる結果は参考程度に留める前提で進める

## 3. 分析パイプライン(推奨順序・使用ファイル/オプション明記)

> **実行状況の凡例**:Step 0.5・Step1(著者帰属1・全体版)・Step2(a)(Act単位)は実測確認済み(2025年再検証)。Baillie参照2作品の規模がColeridge・Southey参照より大きく、Step1・著者帰属2で規模由来のアーティファクトが確認されたため要注意(4.10・4.11参照)。Step2(a)ではさらに、規模とは独立した「Act同士が外部参照より常に近い」という本質的現象も確認された(4.12参照)。Step1(著者帰属2)・Step2(b)(7断片版)・Step3は実測データに基づく確認済み設定。

### Step 0.5:Bootstrap Consensus Tree(実測確認済み:W=500,S=50,MFW=50–200・25刻み)

#### 使用データ

| 項目 | 設定 |
|---|---|
| dz-test | CoSou_Robespierre.txt(全幕結合、5,810語) |
| dz-ref | 9件全てON:Coleridge_Osorio.txt / Coleridge_TriumphofLoyalty.txt / Southey_Wat_Tyler.txt / Southey_BotanyBayEclogue_dialogue_only.txt / Wordsworth_TheBorderers_dialogue_only.txt / HannahMore_Percy_dialogue_only.txt / JoannnaBaillie_Basil_1798_dialogue_only.txt / JoannaBaillie_TheTryal_1798_dialogue_only.txt / JoannaBaillie_DeMonfort_1798_dialogue_only.txt |
| dz-acts | Act単位(CoSou_Act1/2/3.txt)、または断片単位(CoSou_分割1〜4_2.txt+Act2/3)を投入し、それぞれがどう結合するか確認 |
| コンセンサスMFW最小値 | 50(既定) |
| コンセンサスMFW最大値 | 200(既定) |
| コンセンサスMFWステップ | 25(既定) |
| コンセンサス閾値 | 0.5(既定) |

#### 仕組み(内部ロジック)

1. 「MFW最小値〜最大値・ステップ」で指定した範囲(既定では50, 75, 100, 125, 150, 175, 200の**7点**)について、**MFW値ごとに独立したUPGMA木(通常のBurrows' Deltaデンドログラム)を1本ずつ作成**する。これが「複製ツリー(replicate tree)」であり、既定設定では7本生成される
2. 各複製ツリーに現れる**すべての枝分かれ(クレード:どの文書同士が1つのグループを成しているか)**を記録する
3. 全複製ツリー(7本)のうち、**同一の枝分かれが何本の木に現れたか**を数える
4. その出現率(出現本数÷複製ツリー総数)が「コンセンサス閾値」(既定0.5)以上の枝分かれだけを採用し、最終的な1本の合意木(コンセンサスツリー)を構築する

これは、以前から行ってきた「複数MFW間の一致性を手作業で確認する」というチェックを、MFW=50〜200の範囲で自動的に多数決検証する機能にあたる。

#### 見方:パーセンテージの意味

各結合点に赤字で表示される%は、**「そのグルーピングが、7種類のMFW設定のうち何%で再現されたか」**を示す(統計学のブートストラップ支持率と同じ発想)。

| 支持率の目安 | 解釈 |
|---|---|
| 90〜100% | MFWをどう変えてもほぼ常に同じ形でまとまる。極めて頑健な結合 |
| 60〜89% | 大半のMFW設定で再現されるが、一部の設定では崩れる。中程度の信頼性 |
| 50〜59%(閾値ぎりぎり) | 半分程度のMFW設定でしか再現されない。MFW依存的で弱い結合。結論の根拠にするのは避ける |
| (閾値未満で非表示) | どのMFWでも過半数の支持を得られなかった枝分かれ。ツリー上には現れず、該当する文書は多分岐(未解決)の状態でまとめて表示される |

#### 見方:高さ(縦位置)の意味 ── 通常のデンドログラムと逆

**最も誤解しやすい点。** Step2の通常デンドログラムは、結合点の高さ=Delta距離(近いほど低い位置で結合)だが、**Step0.5の高さは距離ではなく、そのままパーセンテージを表している**(ツール実装のコメントにも「高さは模式的にサポート率0〜100%に比例させたもので、Delta距離ではない」と明記されている)。

- 結合点が上(100%側)にあるほど:支持率が高く頑健なグルーピング
- 結合点が下(閾値50%側)にあるほど:ぎりぎり閾値を満たしただけの弱いグルーピング

「下で結合=距離が近い」という通常のデンドログラムの感覚をそのまま持ち込むと、上下の意味を逆に読んでしまうため注意すること。

#### 分析手順(このコーパスでの実施方法)

1. まず**参照テキスト同士の頑健性を確認**する:Osorio-Triumph(Coleridge同士)、Act II-Act III(Southey同士、既知の同一著者ペア)が高い支持率(90%以上が望ましい)で結合しているかを見る。ここが低い場合、MFW範囲やコンセンサス閾値の設定自体を見直す
2. **検証したい断片(分割1〜4、またはAct I)がどのクレードに、何%の支持率で参加するか**を確認する
3. 支持率が90%以上であれば、Step2で見た単一MFW(例:MFW=30)での結果がMFW選択に依存しない頑健な結果であることの裏付けとして採用してよい
4. 支持率が50〜60%程度、あるいは該当する枝分かれ自体がツリーに現れない(多分岐のまま)場合、Step2の単一MFW結果は「その1つのMFW値でたまたまそう見えているだけ」の可能性が高く、結論の主根拠としては使わず、参考情報にとどめる
5. MFW最小値・最大値の範囲を必要に応じて調整する(例:短い断片を含む場合、MFW=200は不安定になりやすいため、最大値を100程度に下げて再実行し、結果が変わるか確認するのもよい)

#### 実測結果(2025年再検証時、W=500・S=50・MFW=50–200・25刻み)

- **CoSou_Act1・Act2・Act3が、どの外部参照よりも先に相互結合**(Act1-Act2:100%、+Act3:86%)。これは「Act I・II・IIIが、外部のどの参照著者よりも、まず互いに似ている」ことを意味し、**題材・登場人物・史実の共有(主題効果)が著者性の識別より優位に働いている可能性**を示す重要な所見
- 外部参照側では、Southey(Wat Tyler・Botany-Bay)・Baillie(TheTryal)が71%で近接する一方、Coleridge(Osorio・Triumph)・Wordsworth(Borderers)も71%で近接するなど、**Coleridge/Southeyのきれいな2群への分離は見られなかった**
- 総じて支持率は71〜86%(Act1-2-3の組を除く)であり、閾値50%は上回るが90%以上の「極めて頑健」な水準には届いていない。**この設定(MFW=50–200)での外部参照とのクラスタリングは中程度の信頼性にとどまる**と解釈すべき

### Step 1(著者帰属1・実測確認済み):テスト対象全体のRolling Delta

| 項目 | 設定 |
|---|---|
| dz-test | CoSou_Robespierre.txt(5,810語) |
| dz-ref | Step0.5と同じ9件、全てON |
| dz-acts | CoSou_Act1.txt / CoSou_Act2.txt / CoSou_Act3.txt(Step2用に同時投入) |
| ウィンドウ幅(W) | 500語 |
| ステップ幅(S) | 50語 |
| MFW | 100(既定) |

#### 仕組み(Step2の通常Deltaとの違い)

Step1のY軸(Deltaスコア)は、Step2(文書単位の標準化)とは異なる基準で計算される。

1. 各参照テキスト自体を、本編と同じW・Sで内部的に窓分割する(例:Osorio 16,090語なら窓約630本、Triumph 3,156語なら窓約115本)
2. その参照テキスト**内部の窓ごとのばらつき**から、参照ごとに独立したμ・σを算出する
3. テスト対象の各窓について、「この窓は参照Xが普段どの程度ばらつくかという基準に照らして何σ分ずれているか」を計算する

これにより「1文書=1サンプル」という極端な不安定さは解消されるが、**参照テキストが長いほど窓の本数が多くなり、μ・σの推定自体がより安定(低ノイズ)になる**という別の非対称性が残る。窓数の多い参照(長い参照テキスト)ほど、真の文体的近さとは無関係にDelta値で「勝ちやすくなる」可能性がある点に注意(下記実測結果で顕在化)。

#### 見方:著者帰属1で確認すべきこと

1. 既知の境界(語2068=Act I/II、語4182=Act II/III)付近で、Coleridge2本→Southey2本への交差・逆転が起きるか
2. 他の5参照(Wordsworth・Hannah More・Baillie3作品)が終始遠い位置にとどまるか(=妥当な候補除外の裏付けになるか)
3. 交差が境界のちょうど語2068・4182で起きるか、それより手前で起きるか(手前で起きればAct I内分割点と呼応する手がかりになる)

#### 実測結果(2025年再検証時)

CSVを解析した結果、**当初の想定より複雑な実態が判明した**。

| 語範囲 | 実際の最近傍参照 |
|---|---|
| 250–500, 600–900, 2400–2450 | Coleridge_Osorio |
| **900–2000**(Act I内、約1,100語の最大区間) | **Baillie_Basil** |
| 2000–2100 | Hannah More_Percy |
| 2100–2200, 4500–5100, 5500–5600 | Southey_Wat Tyler |
| 2450〜5450の大半 | **Baillie_Basil / Baillie_De Monfortが交互に支配** |
| 5600–5987 | Southey_BotanyBay |

**重要な問題点**:既知のSouthey区間(Act II・III、語2068–5810)であっても、**最近傍として最頻出なのはSoutheyの参照2作品ではなく、Baillieの`Basil`・`De Monfort`である**。Southeyが最近傍になるのは語2100–2200・4500–5100・5500–5987というごく限られた範囲にとどまる。Act I内でも語900–2000という広い区間でBaillie_Basilが最近傍となり、「他の5参照が終始遠い位置にとどまる」とは言えない。

**解釈**:Baillie2作品(計約39,477語)がColeridge2作品(計19,246語)・Southey2作品(計9,805語)よりはるかに大きく、上記「窓数の多い参照ほど推定が安定し勝ちやすい」という非対称性が、この結果に強く影響している疑いが強い。真の文体的近さというより、**コーパス規模由来のアーティファクトの可能性がある**。

**Bootstrap Consensus Tree(Step0.5)との整合性**:Step0.5でAct I・II・IIIが外部参照より先に相互結合していた所見(主題効果の優位)と、この「Baillieが規模で押し切る」現象は、**いずれも著者性以外の要因(主題・コーパス規模)が結果を支配しうる**という同じ懸念を異なる角度から裏付けている。

**今後の対応**:9件フル参照でのStep1は、参照コーパスの規模バランスがとれていないため、著者帰属の直接的な証拠としては使わない方がよい。絞り込み後の4件参照(Osorio・Triumph・Wat Tyler・Botany-Bay、総語数の差が比較的小さい)での再実行、あるいは9件のまま使う場合はBaillie2作品を一部区切って分量を揃えるなどの対策を検討する。

#### 重要な検証:Baillie_Basil混入による見せかけの最近傍

CSVを機械的に解析した結果、上記6件参照(Baillie_Basil含む)では、**3つの分割点すべてで実際の最近傍がColeridgeでもSoutheyでもなくBaillie_Basilだった**ことが判明した(著者帰属1で確認した規模由来のアーティファクトと同じ現象。Basil=21,806語は他の参照より頭一つ大きい)。

#### 検証:Baillie_BasilをOFFにして再実行した結果

Baillie_Basilを除外して再実行したところ、**最近傍が再びColeridge/Southey間で入れ替わる、妥当な挙動に戻った**。

| 分割点 | 1位 | 2位 | 差 |
|---|---|---|---|
| 語1000(「Southey 1」) | Wat Tyler 0.826(Southey) | Botany-Bay 0.863(Southey) | 明確な差 |
| 語1325(「Coleridge」) | Wat Tyler 0.924(Southey) | Osorio 0.936(Coleridge) | **僅差(0.012)** |

ただし、語1325・1850の交差は**僅差**(特に語1850は事実上のコイントスに近い水準)であり、単純な「勝ち負け」の解釈には注意が必要。この僅差である事実自体が、Step3のPHASE2(MFW感度分析)で観測された「一様に遠ざかる」「特定1テキストのみへの選択的接近」といった単純でない挙動と整合的である。

**教訓**:9件・6件のようなフル参照セットでRolling Deltaを実行する際は、**必ず規模の大きい参照(Baillie・Wordsworth等)を含めた状態と除外した状態の両方で分割点・交差点を比較する**ことを標準手順とする。

### Step 2:全体構造の把握(2パターン)

#### 重要な訂正:Step2にウィンドウ幅・ステップ幅は関与しない

## 4. 各段階での必須チェックポイント(前回判明した落とし穴)

### 4.1 参照テキストの絞り込みタイミング

Step1(分割点探索)とStep3(詳細検証)で、参照テキストの構成(何件ON/OFFにするか)を変える場合、**Step3実行の直前に必ずチェックボックスの状態を確認する**こと。前段の設定が残ったまま次段階に進んでしまうミスが起きやすい。

### 4.2 GI法の設定

| オプション | 推奨 | 理由 |
|---|---|---|
| インポスター抽出率 | `windowImposters`使用時は0.3〜0.5、不使用時は1.0 | プールが小さい(4件程度)場合、抽出率0.5のままだと不安定 |
| `windowImposters` | **必ずON** | OFFかつ抽出率1.0では、インポスター側のランダム性が失われ、GI法として機能しなくなることが前回判明した |
| ウィンドウ幅・ステップ幅(水増し用) | Step1で使った細かい値(例:300語/25語)を**流用しない**。600語/400語程度に別途設定する | 細かい値のまま流用すると隣接窓の重複率が90%を超え、疑似的な多様性しか得られない |
| 語数均等化 | ON(既定) | 参照テキスト間の分量差(数千〜1万語超)を吸収するために必須 |
| 反復回数 | 200以上 | 小さいテキスト・小さいインポスタープールでは分散が大きいため |

### 4.3 結果の読み取り順序

単一の指標だけで結論を出さないこと。以下の順で確認する。

1. PHASE1(基本Delta)→ 変化ありそうか
2. 参照ランキング(どちらの方向への変化か)
3. GI法(統計的に頑健か、複数設定・複数回実行で一致するか)
4. PHASE2(MFW=30〜50でも一貫するか、高MFWでのみ見える現象でないか)
5. PHASE3〜5(具体的に何が変わったか)

### 4.4 PHASE3(語彙変化Top50)を見る際の必須確認

**変化語リストの上位に、登場人物名やその場面固有の呼称が含まれていないか、毎回確認すること。** 前回、`couthon`→`adelaide`、`barrere`の増加など、**著者性ではなく単に登場人物構成が変わっただけ**の語が繰り返し上位に出現した。これが混じっている場合、その分割点の変化は「文体的影響」よりも「場面転換・登場人物交代」で説明できる可能性を優先して検討すること。

### 4.5 Burrows' DeltaとEder's Deltaの乖離

高MFW(200以上)で両者の結果が乖離した場合、**Eder's Delta側を優先する**(低頻度語の不安定な推定に引きずられていない可能性が高いため)。

### 4.6 ツールの自動生成サマリー文への注意

「AFTER区間に最も近い参照テキスト:○○」といった自動要約文が、**実際の数値テーブルと矛盾する場合がある**(前回実例あり)。自動要約は参考程度にとどめ、必ず生の数値を確認すること。

### 4.7 物語的収斂(ジャンル効果)と文体的影響の切り分け

Act Iの後半が政治的な結末(次幕への受け渡し)に向かう場合、**同じクライマックスに収束する内容ゆえの語彙的な近さ**が生じうる。これを「著者的影響」と区別するには：

- 同じ場面ジャンル(政治的内容)を保ったまま別の分割点で比較する対照実験を行う(前回、分割点1がこの役割を果たした)
- 変化が政治語彙の増減で説明できるか、機能語(代名詞・二人称等)の変化で説明できるかを区別する

### 4.8 短い断片(300語未満)の扱い

MFW=100以上の結果は統計的信頼性が低い。MFW=30〜50を中心に解釈し、結論の主根拠にはしない。

### 4.9 Step0.5(Bootstrap Consensus Tree)解釈時の注意

- 結合点の**高さは距離ではなく支持率(%)**であり、Step2の通常デンドログラム(高さ=距離)と読み方が逆になる。混同しないこと
- 閾値未満の枝分かれはツリー上に現れず多分岐として表示されるため、「なぜ複数の文書が1点にまとまって出るのか」と疑問に思ったら、それは「頑健な2分割の答えが出なかった」ことを意味すると解釈する
- 支持率50〜60%程度の結合は、Step2で見た単一MFWの結果を裏付ける根拠として使わないこと

### 4.10 Step1・参照コーパスの規模非対称性(9件フル参照使用時に必須の確認事項)

Step1は参照テキストごとに内部窓分割でμ・σを作るため、**参照テキストが長いほど窓数が多く、μ・σの推定が安定し、Delta値で「勝ちやすくなる」**傾向がある。実測では、9件フル参照(Baillie3作品を含む)でのStep1実行時、既知のSouthey区間(Act II・III)でもBaillie(計約39,477語、Southey計約9,805語の4倍)が最近傍として最頻出になるという、規模由来と疑われるアーティファクトが確認された。9件フル参照での結果を著者帰属の直接的根拠として扱わないこと。可能であれば参照テキストの総語数を著者クラス間で揃えるか、絞り込み後の4件参照(規模差が比較的小さい)での結果を優先すること。

### 4.11 大規模参照(Baillie等)を含めた場合と除外した場合の両方を必ず確認する

著者帰属2(Act I単体、6件参照)でも同様の現象が確認された:Baillie_Basil(21,806語、他の参照より頭一つ大きい)を含めた状態では、Rolling Deltaで検出した3つの分割点すべてで、実際の最近傍はColeridgeでもSoutheyでもなくBaillie_Basilだった。グラフ上の「Southey/Coleridge」ラベルは、Baillie・Wordsworthを除いた4ライン(Coleridge2本・Southey2本)だけを見た交差点であり、6ライン全体での真の最近傍ではなかった点に注意。

**標準手順**:規模の大きい参照(目安として、他の参照の2倍以上の語数を持つもの)を含む構成でRolling Deltaを実行した場合、**その参照を除外した状態でも同じ分割点・交差点が再現されるかを必ず確認する**。除外後も同じ位置で交差が起きれば、その分割点はアーティファクトではなく実質的な現象と判断してよい。今回のケースでは、Baillie除外後も分割点1・2・3の交差は概ね維持されたが、うち2箇所(語1325・1850)は僅差(0.002〜0.012)であり、結論の強さを慎重に評価する必要があった。

### 4.12 Step2(a):Act同士が外部参照より常に近い現象(規模アーティファクトとは別種)

Step2(a)の実測(9件版・4件版とも)で、**Act I・II・IIIの3つすべてにおいて、最近傍は常に他のActであり、外部参照が最近傍になることは一度もなかった**。この現象は、Baillie等の大規模参照を除外しても消えないため、4.10・4.11の規模由来アーティファクトとは異なる、**同じ戯曲の3幕が共有する題材・登場人物・語彙(主題効果)による、より本質的な現象**と考えられる。

- Step2(a)のデンドログラムの結合構造(どのActとどのActが先に結合するか)を、著者性の直接的な証拠として使わないこと。参照構成(9件か4件か)によって結合順序自体が入れ替わりうる際どい水準であることが確認されている
- 代わりに、**各Actから各参照への個別距離の大小関係**(Coleridge系参照とSouthey系参照のどちらに近いか)を見ること。これはStep1・Step3で一貫して採用してきたアプローチと同じ

### 4.13 PCA散布図とデンドログラムで評価が割れる断片への対応

同じ距離行列でも、PCA(2次元投影)とデンドログラム(階層的クラスタリング)は異なる見え方をすることがある。実測では、分割4_1(私的場面断片)について、PCAでは「分割2・3付近に位置し孤立していない」と読めたが、別途確認したデンドログラムでは「孤立ブランチ」と判定されており、**同じ生データから逆の印象を受ける**事例が確認された。

**対応**:このような断片については、
1. 生の距離行列で、その断片の最良リンク(最小距離)の値が、他の正当なクラスタ形成リンク(例:同一著者の参照ペア、既知の同一著者Act同士)と同水準かを確認する
2. 最良リンクは強くても、最大距離(その断片から最も遠い相手への距離)が突出して大きい場合、デンドログラムの結合方式(complete linkage等)によっては孤立ブランチとして描画されうる点に留意する
3. PCA・デンドログラムのどちらか一方だけで判断せず、**必ず両方を突き合わせ、最終的には生の数値を優先する**

## 6. 前回の分析全体を通じた教訓(要約)

- 統計的に「近づいた/遠ざかった」という結果が出ても、**その原因が著者性・ジャンル・登場人物構成・物語的収斂のいずれによるものかは、追加の内容分析なしには判別できない**
- 参照コーパスに、検証対象と同ジャンルの比較対象(例:私的独白場面に相当するColeridge作品)が欠けている場合、「どの著者からも一様に遠い」という結果が、著者性の異質さではなく**参照コーパスの空白**を意味することがある
- 前提(Act II・IIIの著者確定情報)そのものが再検証の対象になりうることを、常に念頭に置く
- **参照コーパスの規模(総語数)が著者クラス間で大きく異なる場合、Step1のような窓分割ベースの手法であっても、規模の大きい参照が「勝ちやすくなる」アーティファクトが生じうる**(Baillie2作品がSouthey2作品の4倍の規模を持つ状態での実測で確認)。9件フル参照での結果は、この観点から慎重に扱うこと
- Bootstrap Consensus Tree(Step0.5)でAct I・II・IIIが外部参照より先に相互結合する現象は、**主題・題材の共有が著者性の識別より強く効いている**可能性を示す、見過ごせない所見である
- **大規模参照を含めた分割点検出は、その参照を除外した再実行で必ず検証する**こと。著者帰属2では、Baillie_Basil込みだと3分割点すべての最近傍がBaillieに入れ替わっていたが、除外後は概ねColeridge/Southey間の交差として妥当性が回復した。ただし僅差(0.002〜0.012)の箇所もあり、「交差が起きた」という事実だけで結論を強く主張しないこと
- **Step2(a)Act単位の実測で、Act I・II・IIIが常に外部参照より互いに近いことが確認された。これはBaillie等の大規模参照を除いても消えない、より本質的な現象(3幕共通の主題効果)であり、規模アーティファクトとは区別する必要がある。** デンドログラムの結合構造そのものを著者性の証拠として使うのは避け、各Actから各参照への個別距離の順位を見ること
- **「Southeyへの接近」に見える現象は、複数の分割点を比較すると質的に異なることが判明した**:分割点1はSouthey2作品両方への接近(支持力が比較的高い)、分割点2は特定1作品(Botany-Bay)のみへの選択的接近(主題的一致の疑い)、分割点3は全参照からの孤立(短い断片による不安定性の疑い)。**「変化が検出された」という結果を分割点間で単純に足し合わせて仮説を補強しないこと。** 個々の分割点ごとにMFW感度分析で挙動のパターンを確認し、質的な違いを踏まえて評価すること
